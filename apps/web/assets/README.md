# EgonarMarket storefront assets

These filenames are the canonical paths used by the three storefronts:

- `user-saveurs-thieboudienne.jpg` — Saveurs du Sénégal / Thiéboudienne
- `user-saveurs-plats-menus.jpg` — Plats & Menus
- `user-saveurs-delivery.png` — Se faire livrer (PNG)
- `user-delivery-cover.webp` — Livraison section
- `user-evasion-monument.jpg` — Évasion / Monument

The frontend uses these local assets first and falls back to a web image if an asset is unavailable, so a missing asset does not break the page.
